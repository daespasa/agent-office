# Asset provenance

`office-concept.svg` is an original static vector composition created for this repository on 2026-10-30 and distributed under the repository MIT license. It is a design schematic, not a running application or final sprite kit. No pixels, artwork or logos from the reference games or the user screenshot are included.

Future assets need a source/author/license record and must be usable in an open-source distribution. Do not introduce externally hosted assets or network fonts as a requirement for the offline demo.
